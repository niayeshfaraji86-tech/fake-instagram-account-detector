# 🤖 Instagram Fake Account Detector

An end-to-end Machine Learning project to detect fake Instagram accounts using Decision Trees and Python.

## 📌 About the Project
With the rise of automated bots and fake profiles on social media, identifying them is crucial. This project analyzes account features (such as profile picture, bio length, follower/following ratios, and posting activity) to classify whether an Instagram account is real or fake using a **Decision Tree Classifier**.

## 🛠️ Tech Stack & Libraries
- **Language:** Python 🐍
- **Environment:** Jupyter Notebook / VS Code
- **Data Manipulation & Analysis:** Pandas, NumPy
- **Machine Learning:** Scikit-Learn (Decision Tree)
- **Visualization:** Matplotlib, Seaborn

## 📂 Project Structure
- `i.ipynb`: Main Jupyter Notebook containing data preprocessing, exploratory data analysis (EDA), model training, and evaluation.
